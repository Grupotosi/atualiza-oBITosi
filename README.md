# Atualizações do Dash Compras Tosi

Este repositório público hospeda somente os arquivos de atualização do aplicativo Dash Compras Tosi.

Os instaladores não contêm planilhas nem dados empresariais. A planilha é vinculada localmente em cada computador.

## Arquivos de cada Release

- `Dash-Compras-Tosi-Setup-X.Y.Z.exe`
- `Dash-Compras-Tosi-Setup-X.Y.Z.exe.blockmap`
- `latest.yml`

O aplicativo consulta automaticamente a Release mais recente sempre que é aberto.
